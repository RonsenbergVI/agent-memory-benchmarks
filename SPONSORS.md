# Sponsoring the benchmark

agent-memory-benchmarks is independent infrastructure: one uniform methodology,
the same models for every system, results generated only by CI from tagged
code, every run artifact public. Its costs are almost entirely API spend for
official runs — measured per-run in the committed `summary.json` accounting.

Sponsorship funds those runs. Concretely, what more funding buys:

- **More systems.** Eight by October, twelve by December — each addition is a
  full ingest and query sweep across both datasets for a new adapter.
- **The agentic tier.** Every system measured a second way, with extraction
  stripped and one identical agent in front of each storage backend. It
  isolates retrieval quality from extraction quality, which nothing else in
  this field does — and it costs an agent loop per question per system.
- **Larger k sweeps.** Measuring downstream answer accuracy out to k=100 to
  test whether retrieval precision still matters at large context.
- **More datasets**, and repeat runs where variance is doing the talking.

## How to sponsor

- **GitHub Sponsors** — the button on this repo.
- **Organizations** that need an invoice: open an issue with the `funding`
  label and we'll sort out the mechanics.
- **API credits** (OpenAI, Anthropic, etc.) count as sponsorship and are
  disclosed exactly like cash.

## The neutrality policy

The benchmark's entire value is that nobody can buy a number. So, before any
sponsor existed, the rules:

1. **Sponsorship buys nothing about results.** No influence on methodology,
   configurations, datasets, run timing, presentation, or inclusion. Results
   are generated by CI from tagged code; there is no human step where
   influence could apply.
2. **All funds are pooled.** Sponsors fund the run pool, never a named
   system's runs.
3. **All sponsorship is disclosed.** Every sponsor is listed below.
4. **Sponsors that are also benchmarked projects are flagged as such** in
   that list, and capped so no benchmarked vendor is the majority funder.
5. **Credits are disclosed like cash.**
6. **Inclusion and methodology changes** follow the public issue process,
   sponsor or not.
