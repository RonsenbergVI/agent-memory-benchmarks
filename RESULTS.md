## Plots

Every question is a binary verdict — the judge marks the agent's answer correct or not — so the headline is judge accuracy, drawn with its 95% Wilson interval; session-level retrieval recall says whether the agent found the evidence at all. Written by `amb plot all` into `plots/<dataset>/`, one directory per dataset (or `plots/<dataset>/<variant>/` for a dataset whose variants are separate experiments). Each section opens with its sweeps over k — the same overview the [README](README.md#results) shows — followed by the detail per k.
