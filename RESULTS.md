## Plots

Every question is a binary verdict — the judge marks the agent's answer correct or not — so the headline is judge accuracy, drawn with its 95% Wilson interval. Written by `amb plot all` into `plots/<dataset>/`, one directory per dataset (or `plots/<dataset>/<variant>/` for a dataset whose variants are separate experiments). Each section opens with its sweeps over k — the same overview the [README](README.md#results) shows — followed by the detail per k.

### locomo

#### locomo: scores vs k

One line per system across the k sweep, newest run per system and k.

![Judge accuracy vs k](plots/locomo/k_accuracy.png)

#### locomo: scores vs hits returned

The same sweep, placed at the hits each k actually returned: k is the budget granted, hits per query what a system spent of it. Compare systems at a matched spend, where returning fewer hits than allowed cannot pass for ranking better.
